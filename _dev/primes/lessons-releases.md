# Lessons: Releases

Failure records for `_dev/primes/prime-releases.md`. Read the matching family before changing release payloads, changelog history links, or the shipped-package reference contract.

- [family: canonical-link-outlives-its-target] 0.294.1 (in place, 2026-09-05): **a canonical history link names a path, and an archive move renames that path underneath it.** `skills/do-work/tools/do-work-cli/lessons-do-work-cli.md` linked REQ-503, REQ-504 and REQ-505 at `do-work/archive/REQ-NNN-*.md`. Those records were later consolidated into `do-work/archive/UR-098/`, so `_dev/tests/shipped-package-reference-contract.sh` reported three untracked blob targets and the canonical gate exited 1 on every run — for three path segments no queued request owned, which is why it surfaced as an unrelated red gate holding three unrelated claims. The link text carries no reference to the record's identity, only to where it sat that day, so nothing updates it when the record moves. When a shipped file links a repository record by path, any later move of that record must sweep the links, and the sweep is `grep -o 'blob/main/do-work/archive/[^)#]*'` over every shipped file with the existence check applied to each hit.

- [family: canonical-link-outlives-its-target] 0.303.1 (in place, 2026-09-05): **the same trap fired again four hours later, from the other direction.** The first occurrence was an archive consolidation someone else had done; this one was caused by an ordinary request closing. Finalizing REQ-573 closed UR-115, which moved REQ-574's record from `do-work/archive/` into `do-work/archive/UR-115/`, and the lesson link naming the old flat path went stale in the same transaction that created it. **Closing a user request is a link-breaking event**, not just an archive tidy-up: any shipped file linking a record of that request by path must be swept in the same change. Run the sweep above before the release, not after the gate reports it — the gate is the slowest possible place to find this, and it holds every other request behind it.
