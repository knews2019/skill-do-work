- 0.235.0: when a pipeline rule cannot use the pipeline's own convention, that is the signal to move the rule out of the pipeline, not to invent a second convention. The standing prose-reconciliation sweep was a REQ that never reached a terminal status, so it could not use `commit:` for provenance — and two branches independently invented the same workaround, a hand-written hash on a body `## Drains` line, the one write in the pipeline bypassing `record-commit-hash.sh`. The workaround was cheap each time; what was expensive was that every new selector, filter, and terminal-set reader had to be taught the exception, so the cost arrived in installments and never looked like a decision. Count the carve-outs before hardening the newest one: a mechanism that needed one in every selector, filter, terminal-set reader and provenance rule it touched, across two skills, is not worth guarding — it is worth deleting.
- 0.221.0: a contract stated where it is introduced does not reach the readers it invalidates. The Fold-First Rule landed in `capture.md` and left four downstream contracts wrong at once — `verify-requests.md` still selected REQs from the `requests` array a fold deliberately skips (so a folded request graded as a *dropped* requirement), capture's own checklist still counted REQ files a fold does not create, the composed exit summary had no headline for the permanent queue state a standing sweep creates, and the Commit Phase named only "the archived REQ" for a REQ that is never archived (the standing sweep itself was retired in 0.235.0; the lesson is about the readers, not that mechanism). When a rule changes what a field means or what a status can be, grep for every **reader** of that field and that status before calling the rule shipped: the readers are where a contract takes effect, and a rule that only its author's file knows about is half-landed. Two of the four were found and fixed independently on another branch within a day, which is the corollary: when a contract lands half-way, the same holes get found repeatedly by whoever reads the next file down.
