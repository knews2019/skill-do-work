## How to build them

Dispatch each REQ to a builder in its own git worktree (`../skill-do-work2-worktrees/worktree-agent-REQ-NNN-<slug>`), merge each hand-back with `git merge --no-ff --no-commit` before Step 6.25, and keep integration serial. `skills/do-work/actions/work-reference.md` → **Worktree Dispatch Mode** is the contract; it worked cleanly ten times last session.

Every builder brief should carry these, all learned the hard way last session:

1. **Scratch goes in `/tmp` or the worktree — never the main tree root.** One builder left a PNG there.
2. **Include the P-A-U instruction.** Two REQs' checkboxes had to be filled by the orchestrator because the brief omitted it, and `qualify.sh` FAILs on unticked boxes.
3. **Assert page identity inside the same call that reads the DOM.** A shared browser instance silently fed one builder a sibling's page and returned confident, plausible, wrong numbers. Return `location.href` alongside every measurement, or drive an isolated browser context.
4. **A programmatic `.focus()` does not trigger `:focus-visible` in Chrome.** It reports the ring missing when the ring is fine. Use a real `Tab` keypress.
5. **Two REDs when the first is a reference error.** A missing constant proves nothing; put the code in place, break exactly one rule, and let the assertion fail for the reason it exists.
6. **`git stash push` on a clean file stashes nothing** and yields a green run that reads as proof. Reproduce RED by checking out the pre-merge blob by hash instead.
