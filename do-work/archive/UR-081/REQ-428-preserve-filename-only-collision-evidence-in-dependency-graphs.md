## Lessons Learned

**What worked:** Testing through repository discovery into the public dependency graph preserved the real filename/frontmatter mismatch instead of fabricating an internal-only fixture.
**What didn't:** Looking up the graph node before collision evidence downgraded a known ambiguous target into a generic missing target.
**Worth knowing:** Repository collision evidence is authoritative even when no frontmatter identity creates a node for the collided filename ID.
