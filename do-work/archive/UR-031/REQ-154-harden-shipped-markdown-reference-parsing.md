## Root Cause

The guard mixed syntax recognition with broad substring and regular-expression scans: its mask shortened fenced regions and omitted indented code/comments, its link matcher did not apply odd/even backslash parity to structural delimiters, and its one-off destination cleanup decoded only escaped spaces. Non-rendered examples therefore reached the policy validators, while standards-valid escaped punctuation reached path resolution with literal backslashes.

## Decisions

- **D-01 — Keep the parser local and policy-neutral.** Harden the existing scanner with offset-preserving masks, escape-aware delimiters, and ASCII-punctuation normalization; do not add a Markdown dependency or change which resolved targets the downstream source/install and URL-policy checks accept.
- **D-02 — Exercise production helpers in table fixtures.** Keep adversarial Markdown in the executable guard and compare exact normalized target lists, including adjacent live links and mask-offset invariants, so every ignored syntax class also proves that published links remain visible.

**Worth knowing:**
