Which CPU value enters the chart?

Use each row’s recorded total. In the second inventory cold observation the separately rounded components are 0.712 and 0.904 seconds, while the recorded total is 1.615 seconds. Taking separate component medians can also select different observations.

selected.tsv · row 3
What explains the gap between clocks?

Parallel children can accumulate more than one CPU second per elapsed second. Subtracting child CPU from elapsed time cannot isolate I/O. Host snapshots describe machine activity and give no process attribution.

Where does Go accumulated time fit?

It sums elapsed times for top-level Go test pass/fail events. Overlapping tests can count the same interval. Session-start, shell-audit and reused-stage record this field as unavailable (n/a).
