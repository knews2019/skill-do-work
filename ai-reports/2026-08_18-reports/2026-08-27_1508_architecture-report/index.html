INFERREDI02

The agent runs the workflow

Read this repository as an agent-operated workflow with executable helpers. Routers select Markdown actions; those actions direct the agent’s decisions and file changes. Shell tools handle mechanical operations, while the board derives a human view from the resulting records.

Basis: This is an architectural interpretation of the dispatch instructions and helper entry points. It is not a claim that a central application process executes all action prose.

05 / Distribution and maintenance

Replace the suite, preserve project state.

VERIFIEDV24

Installation is a recoverable transaction

The installer validates the archive and manifest before managed writes, presents the candidate changes and asks once. It backs up managed originals, replaces the module trees, writes validated configuration candidates and compares installed bytes. Failure invokes recovery. This is an all-or-recover transaction, not one atomic rename of four directories.
