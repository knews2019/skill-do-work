Work procedures load by phase (0.315.3)

Depth 1 of 3: one line

Work procedures now load one phase at a time, and no check was lost.

Version 0.315.3 split the single instruction file of the work action into a short entry point and eight phase files. An agent now reads a phase file only when that phase starts. The entry point fell from 94,224 to 23,645 bytes, and a simple fix reads 12,693 fewer bytes of procedure text.

One limit: the largest reference file, work-reference.md, was not split and is outside these counts.
