Proposal brief · 14 November 2026 · Rewritten around one review session

Pilot the hand Tinka canvas (O2) on two lineages. Build nothing yet.

This proposal asks whether an optional local Tinka canvas improves how you review ai-report bundles between runs. When you trace one full review session from the end of ai-report second-opinion to the start of the next ai-report revise, options O2 and O3 add staging and pull steps in chat while still requiring the real HTML page for folded details (38–46% of text) and phone or text-to-speech review. Recommend running O2 by hand outside Git on the next two lineages (stop rules R1–R3) before writing docs or building ai-report-canvas (O3), and keep live HTML tiles (O4) deferred.

Every step below carries its surface:
  • chat CLI command, terminal output, or chat prompt
  • real page browser tab on index.html, sibling page, or do-work-board preview
  • canvas local Tinka board at 127.0.0.1 only
  • pilot gate measured rule R1–R3
  • blocked failing check or blocker

Section 2 · Comparing effort, surfaces, and prices
