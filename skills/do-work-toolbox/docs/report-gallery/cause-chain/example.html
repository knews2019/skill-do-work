How output bypassed its 16 MiB cap

  1. The buffer exposed ReadFrom

    Embedding bytes.Buffer made its ReadFrom method available on the capture buffer.

  2. The copy skipped Write

    io.Copy used ReadFrom to drain the process pipe. The cap and truncation flag both lived in the capture buffer’s Write.

  3. Oversized output stayed intact

    The archived reproduction kept 16,777,300 bytes with truncated=false.

The fix closes the bypass. A named buffer field removed the promoted method, routing the copy through Write. The regression test sends 16,777,300 bytes and expects exactly 16,777,216 bytes retained and an overflow error.
