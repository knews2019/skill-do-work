What we checked

  • Measure

    An order is on time if it ships by the end of its promised dispatch date in UTC.

  • Units

    The rate is the percentage of orders shipped on time. Each order counts once.

  • Dates

    The four weeks run from 1 through 28 June. Each order is grouped by its promised date.

  • Scope

    The count covers warehouse orders due in those weeks and excludes cancellations.

  • Arithmetic

    The weekly counts add up to 96 on-time orders out of 100 due, or 96%.

  • Target

    The target is at least 95%. The four-week result cleared it by 1 percentage point.
